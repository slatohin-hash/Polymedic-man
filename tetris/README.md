# Polymedica Тетрис

Медицинский тетрис для смартфона в стиле Polymedica.

Управление:
- свайп влево/вправо — сдвиг фигуры
- резкий свайп вниз — мгновенный сброс
- тап — поворот
- свайп вверх или кнопка «Карман» — отложить фигуру
- на компьютере: стрелки, пробел — сброс, C — карман, M — звук, P — пауза

Особенности:
- бонусы: «Скорая» очищает нижнюю линию, «Скальпель» убирает столбец, «Витамин C» замедляет падение на 10 с
- комбо за линии подряд и всплывающие надписи
- кардиограмма ускоряется, когда куча растёт, и тревожно краснеет у самого верха
- переключатель звука в меню и на паузе

Игра — один файл `index.html`, без зависимостей.
